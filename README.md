# Kendi Kendini Dövülen Kod

## Açıklama

Bu kod, kendi kendini eleştirir, küfür eder, döver ve sonra hemen özür dileyip tekrar dövmeye başlar. Gerçekten çalışır. Gerçekten anlamsızdır. Ama hayat gibi.

### Neden?

Çünkü bazen kod da insan gibi stres atmak ister. Veya atmaz. Bilmiyoruz.

## Çalıştırma

```bash
python dov.py
```

Sonsuza kadar devam eder. Ctrl+C ile kurtulabilirsin (belki).

## Özellikler

- Kendi kendine hakaret
- Rastgele özür
- Sonsuz döngü (bug değil, özellik)
